# 🏛️ CivicPulse — Frontend Command Center

> **Interactive 3D Civic Incident Intelligence & Real-Time Visualization Platform**  
> Built with React 19, Vite, TypeScript, Tailwind CSS, MapLibre GL, and Recharts.

---

## 🌟 Features

- **3D WebGL Command Center Map**: MapLibre GL 3D vector map with dynamic building extrusions, heatmaps, and spatial cluster markers.
- **24-Hour Temporal Replay**: Scrub and animate through 24-hour incident timelines with variable playback speeds.
- **Live KPI Telemetry**: Real-time metrics for incident counts, severity distributions, response velocity, and district strain indexes.
- **AI Intelligence & Citizen Ingestion**: Embedded AI classification modals, live report submission simulation, and predictive volume indicators.
- **Responsive Dark Cyberpunk UI**: Sleek glassmorphic interface optimized for command center operations.

---

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ & npm

### Installation & Run

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Build for Production

```bash
npm run build
npm run preview
```
